# tylercheng00.github.io

Bilingual (English / 繁體中文) personal site for 鄭迪珉 Tyler Tik Man Cheng, served by GitHub Pages from the `main` branch root. Plain HTML/CSS/JS, no build step.

- `index.html` – home page (summary), SEO meta, schema.org Person markup
- `about.html` – background, experience, education, media & recognition
- `ventures.html` – entrepreneurship, Nanotech Innovation, patents, selected projects
- `projects.html` – projects page (biotech, finance, interests) linking to each live project page
- `btrdcc-campus.html` – interactive 3D concept model of the BTRDCC biotech campus in Nusantara (bilingual, self-contained). Uses the self-hosted Three.js r128 in `assets/vendor/three-r128.min.js` and the site fonts; linked from the BTRDCC and Tyler’s Future City cards on `projects.html`. Each building (except the outdoor entrance zone) also has an interior bird’s-eye view — an exploded floor stack built on first open from the `FAC` data in the page (rooms as `[id, x0, z0, w, d, type, zh, en, desc zh, desc en]`, furniture from the `GEN` generators). Share image: `assets/projects/btrdcc-campus.jpg`
- `us-equities.html` + `us-equities.js` – illustrative US IPO and M&A walkthroughs; approved case studies go in `#caseGrid` (template in the HTML comment)
- `styles.css`, `main.js` – styling and the EN / 中 toggle (`?lang=zh` also works)
- Contact details (emails, LinkedIn) live in the `#contact` section of `index.html` (and the contact cards at the bottom of the other pages); the vCard and copy buttons read them from there
- Fonts are self-hosted in `assets/fonts/` (Google Fonts is blocked in mainland China); `tools/vendor_fonts.py` refreshes them
- After editing `styles.css` or any `.js` file, run `python3 tools/build_site.py`: it adds `?v=<hash>` to the CSS/JS links on every page so visitors never get a new page with an old cached stylesheet
- The header menu is defined once in `NAV_GROUPS` (`tools/build_site.py`) and written into every page
- `listing-readiness.html` (source `content/pages/listing-readiness.body.html`) + `readiness.js` – free listing-readiness score, plus a paid full report (action plan, 18-month timetable, venue comparison, document checklist, save as PDF). Payment is a Stripe Payment Link: in Stripe create a Payment Link for the report, set *After payment → Don't show confirmation page → redirect* to `https://tylercheng00.github.io/listing-readiness.html?paid={CHECKOUT_SESSION_ID}`, then paste the link into `STRIPE_LINK` (and the price into `PRICE`) at the top of `readiness.js`. Until then the button asks for the report on WhatsApp. There is no server, so the unlock is not checked against Stripe; the report text (`FIX`, `PHASE`, `DOCS`, venue notes) lives in `readiness.js`
- Android app (Google Play): `app.html` (source `content/pages/app.body.html`) is the free check without the site menu or any payment, wrapped as a Trusted Web Activity. `app.webmanifest`, `app-sw.js` (offline, scope `/app` only) and `assets/app/` icons belong to it; `.well-known/assetlinks.json` links the domain to the app's signing key. Store listing text and graphics: `content/play-store/`
- `contact.html` + `contact.js` – booking calendar (Cal.com) and message form (Web3Forms); set `calLink` and `web3formsKey` at the top of `contact.js`. Until then (or if a service is blocked) the form falls back to the visitor's e-mail app
- `privacy.html` (source `content/pages/privacy.body.html`) and `404.html` are generated by `tools/build_site.py`
- `assets/tyler-cheng-profile.pdf` – two-page profile (EN + 中文); edit `content/profile/profile.html`, then run `node tools/build_profile_pdf.js`
- `clock.js` – contact-page time zones and the markets-page open/closed badge (NYSE holidays also in `tools/nyse_calendar.py`)
- Weekly market report: `tools/fetch_markets.py` keeps daily closes in `data/markets-history.json`; every Saturday `.github/workflows/weekly.yml` runs `tools/weekly_report.py` (data only, fixed templates) and publishes it under Insights
- Daily notes: `.github/workflows/daily.yml` publishes up to five Insights articles straight to `main`. No pull request. GitHub often starts a single morning job hours late, so the workflow tries at 07:17, 08:23, 09:47, 11:17 and 13:23 Hong Kong time. Finished notes in `content/daily/*.md` go out on their `date`, and `data/publish-stamp.txt` keeps the day at five even when an earlier day is still queued. When fewer than five are due, `tools/draft_article.py` writes the rest with Claude and the same workflow publishes them, if the `ANTHROPIC_API_KEY` secret is set
- 简体中文: the EN / 繁 / 简 toggle; 简 converts the Traditional text in the browser with `sc.js` (generated by `tools/build_sc.py` from OpenCC plus a list of mainland word choices; runtime in `tools/sc_runtime.js`). Browsers set to zh-CN / zh-SG / zh-Hans open in 简 by default; `?lang=sc` forces it
- `games/` – browser games hub. `games/alchemy-lab-x/` is a chemistry-lab simulation (Traditional Chinese): `chem.js` holds the reagents and auto-balanced reaction rules, `game.js` the SVG lab scene, characters and actions. Progress is saved in the browser (localStorage). Not linked from the header menu yet
- Page photos: `assets/hero/` (Wikimedia Commons, CC0 / CC BY / CC BY-SA). `assets/hero/credits.json` lists each page's photo, author, licence and source; `tools/build_site.py` places the photo behind the page title with a credit line linking to the source
- Social share preview: `assets/og-image-2026.jpg` (1200×630), built from `content/og/og-image.html` with `node tools/build_og_image.js`
