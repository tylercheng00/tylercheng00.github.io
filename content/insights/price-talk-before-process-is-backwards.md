::: en
Founders like to hear a valuation early. It feels like progress. Without a process — who sees the folder, who can say yes, what the timeline is — the number is entertainment. It will move when the first real document request arrives.

Ask what has to be true for that number to survive a partner meeting. Then go do those things. Coming back with a cleaned file is more useful than arguing about a multiple on an empty calendar.

::: zh
創辦人喜歡早點聽到估值。感覺像進度。沒有流程——誰看資料夾、誰能說 yes、時間表是甚麼——那個數字是娛樂。第一個真正的文件要求一來，它就會動。

問：要讓這個數字活過合夥人會議，甚麼必須為真。然後去做那些事。帶著清理過的檔案回來，比在空白日曆上爭論倍數有用。
