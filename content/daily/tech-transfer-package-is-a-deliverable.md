::: en
Write the package as if a skilled stranger must run the method next month: materials, settings, failure modes, contacts. Updating it after each transfer is part of the science.

Investors may never read every page. They will ask whether the package exists. Yes is a better answer than we can put it together.

::: zh
把轉移包寫成：下個月一個熟練的陌生人必須能跑——物料、參數、失敗模式、聯絡人。每次轉移後更新，也是科學的一部分。

投資者未必讀每一頁。他們會問包在不在。在，比我們可以拼起來更好。
