::: en
Every real program has deviations. What matters is whether they are listed, dated, and assessed. A running log turns a scary question into a managed one.

Start the log before you think you need it. Memory is not a quality system.

::: zh
真正的項目都有偏差。重要的是它們是否被列出、標日期、被評估。一本持續日誌把可怕的問題變成可管理的問題。

在你以為需要之前就開始記。記憶不是質量體系。
