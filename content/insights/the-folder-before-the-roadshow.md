::: en
Roadshow dates feel like progress. Flights, hotels, a sequence of rooms. The work that decides whether those rooms waste everyone's time is quieter: a folder that opens, with names that match, and numbers that survive a second look.

I treat listing readiness as a set of files before I treat it as a story. Cap table that reconciles. Financials that match the last board pack. Contracts that say who owns what. A China-exposure description written in ordinary words, not borrowed from a template. If any of those are missing, the first serious buyer will ask for them on day one. You can either have them, or spend the roadshow promising to send them later.

"Later" is expensive. It turns a meeting into a chase. It also tells the room that the company is still assembling itself. Some buyers will wait. Many will move to the next name on their list.

A useful readiness page on a website is only a map. The real object is the folder. Can counsel open it without you on the call. Can a banker find the latest version without asking which WhatsApp thread holds it. If the answer is no, fix the folder before you fix the deck design.

You do not need perfection to start conversations. You need a baseline that does not collapse under ordinary questions. Build that first. Then book the rooms. The sequence sounds slower. It usually finishes sooner.

::: zh
路演日期感覺像進度。機票、酒店、一連串房間。決定那些房間會不會浪費所有人時間的工作更安靜：一個打得開的資料夾，名字對得上，數字經得起第二次看。

我先把上市準備度當一組檔案，再當故事。對得上的股權表。和上次董事會材料一致的財務。寫明誰擁有甚麼的合同。用普通話寫的中國風險描述，不是從範本借來的。缺任何一項，認真的買家第一天就會要。你要麼已有，要麼整趟路演都在答應稍後補寄。

「稍後」很貴。它把會議變成追討。也告訴房間：這家公司還在組裝自己。有些買家會等。很多人會轉去名單上下一個名字。

網站上的準備度頁面只是地圖。真正的物件是資料夾。律師能不能在你不在電話上時打開它。銀行家能不能找到最新版本，而不必問哪個 WhatsApp 對話裏。答案是否定的，先修資料夾，再修投影片設計。

開始對話不需要完美。你需要一個在普通問題下不會塌的底線。先建那個。再訂房間。順序聽起來比較慢。通常反而比較早結束。
